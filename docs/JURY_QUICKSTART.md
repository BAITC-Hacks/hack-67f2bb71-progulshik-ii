# Запуск проекта для жюри

Проект запускается локально на компьютере проверяющего. Покупать хостинг, создавать аккаунт в приложении или получать API-ключ для демонстрационного режима не требуется.

## 1. Подготовка

Установите Node.js **22.18 или новее** вместе с npm. В терминале можно посмотреть версию:

```sh
node --version
npm --version
```

Перейдите в [репозиторий команды](https://github.com/BAITC-Hacks/hack-67f2bb71-progulshik-ii), выберите основную ветку **main**, нажмите **Code → Download ZIP** и распакуйте архив. Git для этого способа не нужен.

Альтернативный вариант с Git:

```sh
git clone https://github.com/BAITC-Hacks/hack-67f2bb71-progulshik-ii.git
cd hack-67f2bb71-progulshik-ii
```

## 2. Запуск

В распакованной папке с `package.json` откройте терминал:

```sh
npm install
npm start
```

На Windows вместо этих двух команд можно открыть **START_WINDOWS.cmd**. Он использует установленный Node.js и подготавливает зависимости при первом запуске.

При первой установке нужен интернет для загрузки зависимостей. Затем приложение в режиме `mock` работает без внешнего ИИ. Откройте **[http://127.0.0.1:3001](http://127.0.0.1:3001)** и оставьте окно запуска открытым. Чтобы остановить приложение, нажмите в этом окне `Ctrl+C`.

## 3. Что проверить

1. В роли «Бизнес» создайте задачу, получите уточняющие вопросы и сформируйте карточку.
2. Подтвердите неполные сведения, посмотрите замечания к качеству полей, дополните карточку и подтвердите её повторно: рейтинг должен учитывать содержательные ответы.
3. Опубликуйте задачу и найдите её в каталоге.
4. Переключитесь на роль «Команда», выберите профиль и отправьте предложение.
5. В роли «Бизнес» откройте отклики и вручную примите или отклоните предложение.

Готовые тексты и порядок действий — в [DEMO.md](DEMO.md). Для быстрого знакомства доступны 5 опубликованных задач, 5 черновиков, 5 команд и 5 откликов. Это вымышленные данные.

### Проверка качества карточки

Кнопка **«Подтвердить и оценить»** проверяет содержание всей карточки. Случайные буквы и ответы без нужной конкретики не должны давать баллы за соответствующее поле. Подсказки объясняют, что дополнить; источник показывает локальную проверку, ИИ или резервный режим. После правок старый итоговый балл скрывается до повторного подтверждения. Низкий рейтинг по условиям кейса не запрещает публикацию и отклики.

Без ключа эта проверка работает локально. При подключённом ИИ подтверждение дополнительно обращается к провайдеру и расходует API-кредиты; открытие карточки и каталога платных запросов не делает. Локальные правила обнаруживают типовые проблемы, но не заменяют полноценное понимание текста. Ни локальные правила, ни ИИ не подтверждают достоверность фактов. Пошаговые примеры с набором букв, коротким контактом и повторной проверкой приведены в конце [DEMO.md](DEMO.md).

Переключение роли служит для демонстрации: аккаунтов и разграничения доступа нет. «Мои отклики» относится к выбранному профилю команды, а не к вошедшему пользователю.

## 4. Как включить настоящий ИИ

По умолчанию сервер работает в `mock`: вопросы выбираются по отсутствующим полям, ответы переносятся в карточку, новые факты не генерируются. Качество карточки при подтверждении оценивают локальные правила. Этот режим обозначается в интерфейсе.

Чтобы подключить внешний ИИ без изменения файлов:

1. В приложении нажмите **«Настройки ИИ»**.
2. Вставьте собственный ключ в поле **«API-ключ OpenAI»** и оставьте предложенную модель либо укажите доступную вашему API-аккаунту.
3. Нажмите **«Подключить и проверить»**. Для проверки выполняется один запрос с вымышленной задачей, который расходует средства API. Нужны интернет и доступный баланс.
4. После успешной проверки продолжайте работу: перезапускать приложение не нужно.

При неудачной проверке прежние настройки сохраняются. Если ключ уже настроен, поле можно оставить пустым: будет использован текущий ключ. Ключ команды не входит в репозиторий.

Ключ, введённый в окне, хранится только в памяти сервера до его остановки. **После нового запуска сервера введите ключ повторно.** Обновление страницы не сбрасывает подключение. Ключ не сохраняется в браузере, базе или файлах; настройки общие для вкладок этой копии приложения. Окно управления работает только с локальным сервером на вашем компьютере.

Чтобы отключить внешний ИИ, нажмите **«Деморежим»** в этом же окне. При временной проблеме с провайдером приложение само показывает резервный режим и продолжает работу с локальными вопросами и правилами проверки качества.

**Дополнительный способ для постоянной настройки:** скопируйте `.env.example` в `.env`, укажите `AI_MODE=openai`, собственный `OPENAI_API_KEY` и доступную модель в `OPENAI_MODEL`, затем перезапустите приложение. Окно настроек не изменяет `.env`: после перезапуска снова действуют значения из файла, даже если перед остановкой был выбран деморежим.

## Сохранение и повторный показ

Данные хранятся в `data/hub.sqlite` и сохраняются после остановки. Каждая копия проекта имеет собственную базу. Обновление страницы не удаляет опубликованные задачи и отклики. При нажатии «Сохранить черновик» сохраняются также вопросы и ответы; ещё не сохранённая форма дополнительно хранится в браузере.

Для отдельной чистой демонстрации задайте в `.env` новый путь, например `DATABASE_PATH=./data/jury-demo.sqlite`. Если файла `.env` ещё нет, создайте его копированием `.env.example`. После перезапуска появится независимая база с исходными примерами; старая останется на месте. В редакторе начните новую задачу: браузер может помнить незавершённую форму предыдущего сеанса.

## Если не запускается

| Ситуация | Решение |
| --- | --- |
| `node` или `npm` не найдены | Установите Node.js с npm, закройте и заново откройте терминал |
| Ошибка `node:sqlite` | Проверьте, что Node.js версии 22.18 или новее |
| PowerShell запрещает `npm.ps1` | Используйте `npm.cmd install` и `npm.cmd start` либо `START_WINDOWS.cmd` |
| Не найден пакет `express` | Выполните `npm install` в папке проекта |
| Порт 3001 занят | Остановите ранее запущенную копию приложения или задайте другой `PORT` в `.env` и откройте соответствующий адрес |
| Страница недоступна | Убедитесь, что процесс `npm start` работает; откройте адрес вручную, а не `frontend/index.html` |
| После смены `.env` ничего не изменилось | Остановите сервер и запустите снова |
| Ключ не подключается через «Настройки ИИ» | Проверьте интернет, действительность ключа, баланс API и доступ к выбранной модели; прежние настройки остаются активны |
| После перезапуска снова деморежим | Ключ из окна хранится только до остановки сервера; введите его снова или используйте постоянную настройку через `.env` |
| Настройки ИИ недоступны по сетевому адресу | Откройте приложение на самом компьютере с сервером через `http://127.0.0.1:3001` |

Для проверки только серверного сценария доступны `npm test` и `npm run demo`; это не заменяет демонстрацию интерфейса.
