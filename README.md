# AI Sana Challenge Hub

Проект команды **ProGulSHIK II** для HackAlem AI. Веб-приложение помогает бизнесу превратить короткое описание проблемы в задачу для студентов: уточнить сведения, собрать карточку, повысить её готовность и опубликовать. Студенческие команды самостоятельно отправляют предложения, а бизнес вручную выбирает исполнителей.

## Запуск для жюри

Нужен **Node.js 22.18 или новее** с npm. Скачать исходники можно из [репозитория](https://github.com/BAITC-Hacks/hack-67f2bb71-progulshik-ii) кнопкой **Code → Download ZIP**, затем распаковать. Либо:

```sh
git clone https://github.com/BAITC-Hacks/hack-67f2bb71-progulshik-ii.git
cd hack-67f2bb71-progulshik-ii
npm install
npm start
```

При скачивании ZIP выполните последние две команды в распакованной папке с `package.json`. На Windows также можно открыть **START_WINDOWS.cmd** после установки Node.js.

Откройте **[http://127.0.0.1:3001](http://127.0.0.1:3001)**. Интерфейс и сервер запускаются вместе; отдельная сборка не нужна. Окно запуска должно оставаться открытым. Остановка — `Ctrl+C`.

**API-ключ для запуска не нужен.** По умолчанию вопросы создаются локальными правилами; интерфейс обозначает демонстрационный режим. Карточки, рейтинг, каталог и отклики при этом работают с настоящей локальной базой. Для генерации вопросов внешним ИИ можно подключить собственный ключ по инструкции ниже.

## Возможности MVP

- Короткое описание задачи → минимум три уточняющих вопроса → редактируемая карточка из десяти полей.
- Подтверждение человеком, рейтинг 0–100 с расшифровкой и рекомендациями, публикация.
- Каталог всех опубликованных задач: поиск, фильтры темы и готовности, сортировка по рейтингу. Низкий рейтинг не запрещает отклики.
- Демонстрационное переключение «Бизнес / Команда», выбор и создание профиля команды.
- Отклик с идеей, планом, сроком и ссылкой на прототип; просмотр статуса отправленных предложений.
- Просмотр предложений бизнесом и ручное принятие или отклонение. Можно принять несколько команд; автоматического назначения нет.
- Сохранение задач, вопросов и ответов, команд и откликов в SQLite; проверка ввода и защита карточек от перезаписи устаревшей версией.
- Начальный набор: 5 черновиков, 5 опубликованных карточек, 5 команд и 5 откликов.

## Как устроен рейтинг

| Критерий | Максимум |
| --- | ---: |
| Контекст и потребность | 20 — по 10 за поле |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Контакт и формат взаимодействия | 10 — по 5 за поле |

Баллы начисляются только за заполненные и подтверждённые поля. Пустые строки, одни знаки препинания и заглушки вроде «не знаю» или `TBD` не учитываются. Название обязательно для публикации, но не добавляет баллы.

Уровни готовности: **0–39** — требует уточнения, **40–69** — рабочая, **70–89** — готовая, **90–100** — приоритетная. Непубличный статус черновика и низкий уровень готовности — разные вещи: подтверждённую задачу можно опубликовать даже с 0 баллов.

Сохранение изменений карточки, темы или исходного описания опубликованной задачи возвращает её в черновики. Изменённые поля требуют повторного подтверждения; изменение исходного описания снимает все подтверждения. После проверки задачу можно снова опубликовать. Сохранение только вопросов и ответов интервью не меняет подтверждение и публикацию карточки.

## Внешний ИИ — по желанию

Скопируйте `.env.example` в `.env`. Для Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

В локальном `.env` укажите:

```dotenv
AI_MODE=openai
OPENAI_API_KEY=ваш_собственный_ключ
OPENAI_MODEL=gpt-4o-mini
```

Модель должна быть доступна вашему API-аккаунту. Перезапустите приложение. Ключ используется только сервером; `.env` исключён из Git и не передаётся в браузер.

Промпт, формат JSON и обработка ответа находятся в `backend/ai.js`. Используется OpenAI Responses API. Сервер проверяет структуру ответа, сохраняет приоритет введённых человеком сведений и отбрасывает предложения без дословного подтверждения во входных данных. Пользователь проверяет смысл и подтверждает карточку перед публикацией.

Режимы: `mock` — локальные правила без внешних запросов; `openai` — ответ внешнего ИИ; `fallback` — локальные правила при отсутствии ключа, таймауте или некорректном ответе. Текущий результат обозначается в интерфейсе. ИИ не публикует задачи, не начисляет рейтинг и не выбирает команды.

## Архитектура

```text
frontend/                  HTML, CSS и JavaScript без сборщика
  js/app.js                редактор, навигация и переключение роли
  js/http-service.js       связь редактора с API
  js/collaboration.js      каталог, команды и отклики
backend/
  app.js                   HTTP API и выдача интерфейса
  schema.js                поля и валидация Zod
  scoring.js               рейтинг готовности
  ai.js                    промпт, внешний ИИ и резервный режим
  store.js                 SQLite
  seed.js                  синтетические примеры
  server.js                запуск сервера
  tests/                   автоматические проверки
shared/                    типы данных и API-клиент
scripts/demo.mjs            сценарий API с базой в памяти
docs/                      запуск, защита, API и разработка
```

Node.js, Express 5, Zod 4, встроенный `node:sqlite`. При первом запуске создаётся `data/hub.sqlite`; данные сохраняются между перезапусками. У каждого скачавшего проект своя база. Кнопка сохранения отправляет на сервер также текущие вопросы и ответы; ещё не сохранённый ввод дополнительно хранится в браузере. Для установки через pnpm доступен `pnpm-lock.yaml`.

## Команды для разработчиков

```sh
npm run dev:server
npm test
npm run demo
```

Первая команда перезапускает сервер при изменении кода. Тесты используют встроенный `node:test` и имитацию внешнего ИИ. Скрипт `demo` проходит сценарий API с временной базой в памяти, не меняя сохранённые задачи и не расходуя API-кредиты. Полный пользовательский сценарий описан в [DEMO.md](docs/DEMO.md).

## Границы версии

Это готовый к локальной демонстрации MVP. Переключение роли и выбор команды демонстрируют сценарии, **не являются авторизацией**: рабочее пространство общее, проверки прав на уровне аккаунтов нет. Сервер по умолчанию доступен только на `127.0.0.1`. Размещение в интернете не требуется для выбранного способа сдачи.

Данные примеров вымышлены; адреса `example.test` и ссылки на демонстрационные прототипы — заглушки. Рейтинг отражает заполнение и подтверждение полей, а не независимую проверку достоверности или качества текста. Регистрация, чат, загрузка файлов, уведомления и полноценный трекер выполнения проектов не входят в эту версию.
